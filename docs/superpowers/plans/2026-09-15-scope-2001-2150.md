# Hire Intelligence Scopes 2001-2150 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use inline executing-plans in this environment; no subagent/worktree is available.

**Goal:** Extend Hire Intelligence through Scope 2150 with real commercial measurement, evidence-derived event intelligence, contractor workload, predicted equipment clusters, fleet-positioning guidance, and outcome calibration without fabricating commercial evidence.

**Architecture:** Keep raw source evidence and provenance unchanged. Add a pure derived commercial-intelligence module over canonical projects, and link human-entered CRM outcomes to canonical project IDs. Surface derived outputs in one Commercial Intelligence view and the project drawer. Features requiring real BDM outcomes remain visibly data-gated until genuine records exist.

**Tech Stack:** React 19, TypeScript, AppDeploy API/database SDK, existing checkpointed ingestion/backfill architecture.

## Global Constraints
- CALL NOW remains evidence-gated and is never created from a score alone.
- Equipment demand and fleet positioning are PREDICTED, never observed hire requirements.
- Contractors/contacts are not invented.
- Quote/win values and BDM outcomes are human-entered only.
- QA outcomes are excluded from commercial metrics.
- Existing source provenance and licence labels are preserved.
- Existing broken collectors remain deferred unless independently repaired and verified.

## Task 1 — Commercial pilot linkage (Scopes 2001-2020)
- Link new CRM outcomes to canonical project IDs.
- Capture current project signal snapshot at outcome time.
- Produce a top-50 pilot queue and outcome-funnel timing/calibration views.
- Keep calibration empty/data-gated when genuine outcomes are absent.

## Task 2 — Event and transition intelligence (Scopes 2021-2043)
- Derive shutdown, outage, maintenance, mobilisation, restart/reactivation, expansion, procurement and award event tags from published evidence.
- Produce evidence-needed guidance and action recommendations that stop short of CALL NOW.
- Surface negative/cancellation/deferment signals.

## Task 3 — Contractor/equipment action layer (Scopes 2044-2050)
- Aggregate contractor workload from evidence-backed contractor names only.
- Detect geographic/project clustering.
- Aggregate PREDICTED equipment demand by location and class.
- Produce PREDICTED fleet-positioning watch recommendations.

## Task 4 — National coverage framework (Scopes 2051-2100)
- Expose coverage and source-health programme status by jurisdiction/sector using current lawful feeds.
- Mark additional source-dependent capabilities SOURCE-GATED rather than fabricating coverage.

## Task 5 — Proprietary outcome learning (Scopes 2101-2130)
- Calibrate outcomes by signal-quality band, BDM priority decile, stage, contractor and predicted equipment class where genuine linked outcomes exist.
- Maintain zero/empty output when outcome evidence does not exist.

## Task 6 — Decision/fleet layer (Scopes 2131-2150)
- Build predicted regional equipment-demand clusters and fleet-positioning watchlist.
- Show why each recommendation exists, its confidence and source-project count.
- Expose Scope 2150 programme status with OPERATIONAL, DATA-GATED and SOURCE-GATED blocks.

## Verification
- Production build compiles with zero frontend/backend/network errors.
- Existing live refresh and historical backfill remain successful.
- CRM rejects unlinked non-QA outcomes.
- PREDICTED labels remain visible on equipment/fleet outputs.
- CALL NOW remains evidence-gated.
